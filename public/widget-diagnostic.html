5️⃣ Hướng dẫn test thủ công

Bước 1: Mở một tab web bình thường (ví dụ: https://google.com)
Bước 2: Quay lại tab này, bấm "Kiểm tra Tab hiện tại" để xem tab ID
Bước 3: Bấm "Ping Content Script" → nếu ❌ thì content script chưa được inject
Bước 4: Bấm "Inject Widget" → chuyển qua tab web để xem widget
Bước 5: Bấm "Test Alert Toast" → xem toast cảnh báo đỏ trên widget

Nếu content script không load:
• Reload extension tại chrome://extensions
• Refresh lại trang web (Ctrl+R)
• Kiểm tra chrome://extensions → xem errors
• Content script không chạy trên chrome:// pages và chrome-extension:// pages
